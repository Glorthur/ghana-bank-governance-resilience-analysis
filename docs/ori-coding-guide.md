# Operational Resilience Index coding guide

The Operational Resilience Index (ORI) is an additive disclosure index with eight binary items. For each bank-year, an item is coded `1` when the annual report explicitly discloses the relevant resilience governance or control arrangement, `0` when the item is absent after the prescribed review, and blank when unavailable. The score is `SUM(ORI1:ORI8) / 8 * 100`; it is blank if an item is unavailable.

| Item | Construct | Positive disclosure examples |
| --- | --- | --- |
| ORI1 | Operational risk management | Operational-risk framework, management, or controls |
| ORI2 | Board/risk committee oversight | Board or committee oversight of operational, cyber, technology, or information-security risk |
| ORI3 | Business continuity/disaster recovery | Business continuity, disaster recovery, or continuity arrangements |
| ORI4 | Cyber/IT/information security | Cyber, IT, information-security, or technology-risk controls |
| ORI5 | Internal control framework | Internal-control framework, system, or control environment |
| ORI6 | Internal audit/audit assurance | Internal audit, assurance, or independent control review |
| ORI7 | Compliance/regulatory control | Compliance, AML/CFT, conduct-risk, or regulatory monitoring framework |
| ORI8 | Incident/crisis response | Incident, crisis, disruption, breach, or response arrangements |

The evidence register retains the rule, page reference, excerpt, coding method, and adjudication fields for each item. Final codes reflect the audited adjudication process, including retained corrections documented in the manual verification register.
